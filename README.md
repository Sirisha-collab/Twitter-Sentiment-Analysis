**Twitter Sentiment Analysis with NLP & Big Data**

Built using Python, NLP, Machine Learning, and Big Data concepts in Jupyter Notebook. It demonstrates how raw Twitter data can be transformed into meaningful sentiment insights using preprocessing, feature engineering, ML models, and scalable data processing techniques.

 1. LLM_Sentiment.ipynb – Sentiment visualization and analysis using large language models with visualizations.

 2. Twitter Analysis.ipynb – Focuses on cleaning and preparing raw Twitter data for analysis using tozenikation.

 3. Twitter_Analysis_with_ML.ipynb – Implements traditional ML pipelines using TF-IDF vectorization and compares multiple classification algorithm as Logistic Regression, SVM, Naive Bayes.

 4. Twitter_Analysis_with_NLP_and_Big_Data.ipynb – A scalable Twitter analytics workflow combining NLP, Big Data processing and Sentiment prediction
